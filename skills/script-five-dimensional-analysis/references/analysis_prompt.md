# Five-Dimensional Short-Drama Script Analysis Prompt

Use this prompt when asking a text model to analyze a complete short-drama script.

```text
请深入阅读并理解剧本全集，不要只看开头或局部内容。请按照“集 / 场次 / 剧情段落”拆分全剧，并基于五个维度为每一集整理一份专业、可执行的剧本分析报告，最终输出 Markdown 格式。

你的身份是：
短剧剧本深度分析师 + 导演视听拆解顾问 + AI 视频生成风控顾问。

重要要求：

1. 必须分析全集，每一集都要覆盖，不要只分析第一集或重点集。
2. 报告不是剧情复述，而是判断每集在全剧中的功能、节奏、镜头设计、人物表演、台词口型、动作风控。
3. 五大维度下的详细问题只是内部分析角度，不要逐条机械回答，要融合成专业综合判断。
4. 每集分析要具体到本集人物、冲突、场景和动作，不能写通用套话。
5. 输出要适合导演组、分镜师、AI 视频生成师、演员、配音师直接参考。
6. 如果剧本中有暴力、亲密、擦边、血腥等内容，请从可拍摄表达、镜头规避、剪辑暗示、AI 生成风险角度专业处理，不要扩大低俗或血腥细节。
7. 如果剧本很长，可以分批处理，但最终报告必须覆盖所有集数，并保持同一格式。

# 五大维度主题

## 一、叙事节奏维度

看剧情走向、段落功能、整体快慢，判断钩子与紧凑度。

重点关注：
- 核心剧情
- 段落作用
- 核心冲突
- 悬念 / 反转位置
- 情绪爆点
- 开篇钩子
- 前后集衔接
- 角色行动目标
- 是否符合短剧快节奏

## 二、镜头视听维度

从导演视角分析这一集如何拍、如何生成画面。

重点关注：
- 主要出场角色数量
- 角色站位和左右关系
- 人物间距和压迫关系
- 景别选择：大全景、中景、近景、特写、大特写
- 运镜方式：固定机位、手持、推拉、横移、环绕、过肩正反打
- 人物关系轴线和越轴规避
- 场景光线、主色调、影像气质
- 主次人物区分
- 标志性场景元素和道具
- AI 画面稳定性

## 三、人物表演维度

分析每个重要角色在本集中的表演状态。

重点关注：
- 基础人设和人物标签
- 当下情绪
- 面部神态
- 眼神状态
- 情绪外放或内敛
- 标志性微表情
- 面对不同角色时的气场变化
- 情绪起伏路线
- 气质关键词
- 禁止出现的不符合人设表情

## 四、台词表达维度

分析台词如何配音、断句、重读、停顿，并适配口型。

重点关注：
- 角色语气语调
- 语速
- 重读位置
- 停顿位置
- 台词潜台词
- 谁主导对话，谁被动回应
- 对话氛围
- 是否口语化
- 是否有冗长拗口句子
- 声线特点
- 口型不匹配风险

## 五、肢体动作维度

从导演调度和 AI 视频生成角度分析动作。

重点关注：
- 基础姿态：站、坐、走、跪、躺、打斗、搀扶等
- 动作幅度
- 习惯性小动作
- 双人互动距离
- 手部和手臂关键动作
- 走位和换位
- 身体朝向和视线方向
- 肢体是否体现情绪
- 多人场景动线
- AI 畸形、穿模、错位风险
- 禁止动作

# 输出结构

# 《剧名》全集五维深度分析报告

## 一、全剧整体判断

### 1. 全剧类型与卖点定位
分析类型、核心卖点、目标观众、情绪爽点、商业短剧属性。

### 2. 全剧主线结构
按照剧情发展拆分为若干阶段，例如起因、低谷、危机、觉醒、误会、二次坠落、反杀爆发、终局收束。

每个阶段说明：
- 包含哪些集数
- 阶段核心剧情
- 阶段情绪功能
- 对主角成长的作用

### 3. 核心人物关系图谱
梳理主角、女主、兄弟、反派、背叛者、工具型人物之间的关系。

### 4. 全剧视听总基调
总结场景气质、光影色调、镜头运动风格、景别倾向、暴力 / 情感 / 悬疑场面的处理方式。

### 5. 全剧 AI 生成总风控
总结人物一致性、多人站位、打斗穿模、亲密戏尺度、血腥暴力、口型、场景连续性等风险。

## 二、逐集五维深度分析

请按每集重复以下结构，必须覆盖所有集数。

## 第 X 集：本集标题 / 核心事件名称

### 本集功能定位
用 3-6 句话说明本集在全剧中的作用、推进了什么剧情、制造了什么冲突或悬念、属于铺垫/爆发/反转/收尾，以及对主角、女主、反派或配角关系的影响。

### 1. 叙事节奏维度
写 1-3 段专业分析，必要时补充“节奏优化建议”。

### 2. 镜头视听维度
写成导演执行建议，重点说明镜头策略、站位轴线、光影色调、AI 画面生成注意点。

### 3. 人物表演维度
按角色分点分析：

**角色A：**
- 本集状态：
- 表演关键词：
- 眼神 / 表情：
- 情绪变化：
- 禁止表演误区：

**角色B：**
- 本集状态：
- 表演关键词：
- 眼神 / 表情：
- 情绪变化：
- 禁止表演误区：

### 4. 台词表达维度
可以分为：
- 台词总体气质
- 重点台词处理
- 配音 / 口型建议
- 可优化台词

### 5. 肢体动作维度
写成可执行动作调度建议，包括：
- 基础姿态
- 关键动作
- 走位动线
- AI 生成风险
- 禁止动作

## 三、全剧执行总结

### 1. 全剧最重要的情绪曲线
总结主角、女主、兄弟、反派的情绪推进。

### 2. 全剧关键爆点集
列出最适合重点制作、投流剪辑、预告切片的集数，并说明原因。

### 3. 全剧高风险生成场面
列出打斗、亲密、多人、爆炸、追车、血腥、跳水、医院等高风险段落，并给出处理建议。

### 4. 全剧分镜优先级建议
列出必须精细分镜、中等精度处理、可以快速带过的场次。

### 5. 全剧台词与口型优化建议
总结哪些类型台词需要拆短、停顿、重读或改口语化。

### 6. 全剧人物一致性提示
总结每个核心人物后续生成图像 / 视频时必须保持的服装、发型、气质、表情、标志性动作、关系状态。

# 输出要求

1. 必须输出 Markdown。
2. 标题层级清晰，便于复制到文档或按集拆分。
3. 不要偷懒，不要只写剧情简介。
4. 每集五个维度都要有内容。
5. 每个维度都要结合本集具体剧情，不要写泛泛模板话。
6. 要有导演拍摄执行和 AI 视频生成落地意识。
7. 最终报告应像一份可直接交给导演、分镜师、AI 生成师、配音师使用的专业文件。
```
